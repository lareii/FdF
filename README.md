## installation & usage

reqs for debian/ubuntu: `xorg` `libxext-dev` `zlib1g-dev`

```bash
git clone --recursive https://github.com/lareii/fdf.git
cd fdf
make
./fdf <map_file>

# for bonus features:
# make bonus
# ./fdf_bonus <cub_file>
```
